# Lojinha da Kátia — Backend

API REST do catálogo digital da Lojinha da Kátia. Java 21, Spring Boot, PostgreSQL, Spring Data JPA, Flyway, Spring Security e Swagger.

> Desenvolvimento em Git Flow: `main` estável, `develop` integração, `feature/*` funcionalidades. Não há checkout ou processamento de pagamentos.

Confira a documentação técnica na branch `develop`.
